常见问题快速排查

1. 没有声音 / 声音很小？

  • 先用侧边音量键把媒体音量调大（App 内音量滑杆 ≠ 系统音量）
  • 检查左侧静音拨片是否拨到了静音（看屏幕顶部是否出现静音图标）
  • 连接蓝牙音箱/耳机时，确认声音输出到了正确的设备

2. 恢复购买 / 会员没生效？

  • 打开 App → 我的 → 找到"恢复购买"按钮点一次
  • 确保登录的 Apple ID 与购买时一致
  • 仍无效？发邮件给我们，附上 App Store 收据截图

3. 换新手机，数据怎么迁移？

  • 旧手机：我的 → 数据备份 → 导出备份，把 JSON 文件存到"文件"App 或隔空投送
  • 新手机：安装 App → 我的 → 数据备份 → 导入备份选择该文件
  • 全程本地完成，不经任何服务器

4. 语音讲解 / TTS 没有声音？

  • 语音讲解使用系统语音引擎，请确认系统"设置 → 辅助功能 → 朗读内容"中语音可用
  • 部分机型首次朗读需要下载中文语音包

5. 特征频率校准（A/B 测试）不准？

  • 请在安静环境、音量适中时测试，佩戴耳机效果更佳
  • 可多次测试，每次锁定都会保存历史，以最接近主观耳鸣音高的为准

Quick Troubleshooting

1. No sound / sound too low?

  • Raise the media volume with the side buttons (the in-app slider is separate from system volume)
  • Check the silent switch on the side of your iPhone
  • If using Bluetooth speakers/headphones, confirm audio is routed to the right device

2. Restore purchases / membership not active?

  • Open the app → Profile → tap "Restore Purchases"
  • Make sure you're signed in with the same Apple ID used for the purchase
  • Still not working? Email us with a screenshot of your App Store receipt

3. Moving to a new iPhone?

  • Old device: Profile → Data Backup → Export Backup; save the JSON file to Files or AirDrop it
  • New device: install the app → Profile → Data Backup → Import Backup and pick the file
  • Fully local — nothing goes through any server

4. Voice narration (TTS) silent?

  • Narration uses the system speech engine. Check Settings → Accessibility → Spoken Content
  • Some devices need to download a voice pack on first use

5. Pitch matching (A/B test) inaccurate?

  • Test in a quiet environment at moderate volume; headphones recommended
  • You can test multiple times — every match is saved to history; trust the closest one to your tinnitus pitch
